# O-Dev Board

## 0.1.0

First release: GitHub at a glance, read on the Mac through the GitHub CLI signed in there.

- **Repos**: the repositories pushed to most lately, each with its latest commit, its checks, and open pull requests
  and issues.
- **My PRs**: your open pull requests with their checks and review state.
- **Reviews**: pull requests waiting on your review.
- **Inbox**: your GitHub notifications.

The wheel moves down the list and a press opens the row on the Mac. The last board stays on the Car Thing while the
Mac is away.
